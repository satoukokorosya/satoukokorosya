# 株式会社樹の家こころ舎

代表取締役　佐藤慎一郎

2004年開設の設計事務所「シェルター研究所」を前身とし、設計と施工の両方を手がける住宅建築の技術者集団です。

---

## 経営理念

- **心地よさの追求**
- **顧客第一の信念で社業に励み、万物の進歩発展と、全従業員の物心ともに豊かな人生を実現し、社会の平和と繁栄に貢献する**
- **日本の住宅価値を高める**

この三つを軸に経営しています。

---

## 設計思想

> 言葉になる前の感覚を、素材と光と空間の流れで設計し、確かな技術で形にして、住み継がれる財産として残す。

### 1. 出発点：住宅は作品ではなく、住む人の居場所

- 住宅は芸術ではない。住む人の心地よさを最も大切にする
- 社会で演じて過ごす人が多いなか、**本来の自分に戻れる場所**をつくる
- 完成した家を見て、住む人が「**俺の家や**」と感じられること

### 2. 心地よさは五感で感じ、五感は素材感に反応する

- **自然＝本物＝素材**
- 素材感が五感を呼び起こす。例として、農家の土間の涼しさを素材感で表現する
- 五感に響く素材感を設計に織り込む

### 3. 記憶と原風景を設計する

- **人間は記憶で生きている**
- お客様の記憶を借り、心地よさの原風景を家の中で追体験していただく
- お客様の思い出を共有し、家の中に散りばめる
- 人類は何万年も、前が開いて後ろが閉じた洞窟で暮らしてきた。そうした場所を安心できると、DNAが覚えている
- 写真で素材を見たときにも記憶と結びつき、感覚が呼び起こされる。だから**施工事例にも物語が必要**

### 4. 刺激を足すのではなく、引いて設計する

- **静寂とは、音がしないことではなく、刺激が入らない状態のこと**
- スポットライトが当たる場所は落ち着かない
- 動線は、曲がり角が多く目的地が分かりにくい**街中の道**のようにはしない。**環状線**のようになめらかに回遊でき、**高速道路**のように目的のインターまでスムーズで分かりやすい間取りにする
- 五感が落ち着く空間の流れをつくる

| たとえ | 意味 | 住まいでは |
|---|---|---|
| 街中の道（避けたい形） | 曲がり角が多く、目的地がどこか分かりにくい | 曲がるたびに刺激が入り、落ち着かない。迷路のような間取り |
| 環状線 | 止まらずになめらかに回遊できる | 家の中をぐるりと巡れ、行き止まりがなく、暮らしの流れが途切れない |
| 高速道路 | 目的のインターまでスムーズで分かりやすい | 行きたい場所へ迷わず、まっすぐ着ける |

### 5. 光をコントロールする

- 窓は小さくても、高い位置に設けて暗くしない
- 光を壁に這わせるように窓をつくる
- 光が当たる面積が大きければ、暗いとは感じない

### 6. 言葉になる前の感覚を設計する

- 暮らしの感覚をヒアリングする
- 理由を言葉にする前に、感じたことを図面にする
- 玄関に入ったときの感覚を思い浮かべながら設計する
- お客様との**感覚の共鳴**を大切にする

### 7. 間取りは要望の最大公約数ではない

- 欲しいものを全部入れるのではなく、組み合わせて一つの場所に兼ねさせることを考える
- 素直に考えて「この方がいい」と思える形を選ぶ

### 8. 当たり前を積み重ねると、本物の家に近づく

- 誰でもできることをしっかりやらない会社が多い。当たり前のことができないのが業界の現実
- 材料が生かされる施工をし、家の機能が果たされるようにする。それを「**うちはやろう**」

### 9. 設計と施工の両方を担う技術者集団

- 心地よさを表現する設計と、それを形にする技術の両方が必要。だから設計事務所だけでなく工務店も経営している
- イメージした通りに現場で施工するのはかなり難しい
- 棟梁のやり方が、そのまま施工手引書になっている
- スタッフは設計・施工のプロフェッショナル、つまり技術者として育てる

### 10. 家を財産にすることを、日本の当たり前に

- ご縁のあった方の**財産**をつくっている
- 住み終えたら解体するのではなく、多くの人が住みたいと思う家をつくり、住み継がれる財産にする
- それが**日本の住宅価値を高める**ことにつながる

### 11. 土地に対する価値観（何を感じて、何を設計するのか）

- 海・山・川がどこにあるかで、風の吹く時間帯が変わる。土地ごとの風を読んで設計する
- 窓から切り出せる風景を探す
- 道路から見たときの建物の表情を整える

### 12. 太陽に対する設計

- 太陽は東から上り、西に沈む。**設計にも原理原則がある**

### 13. 温熱環境

- **夏の太陽は高く、冬の太陽は低い**。その違いを利用して室温をコントロールする

### 14. 庭などの中間領域に対する価値観

- 庭は、プライベートとパブリックの**緩衝地帯**
- **よい家とよい庭が揃って、よい家庭**

### 15. 空間の広がり

- 内と外の素材を同じものにし、**境界線を曖昧にする**

### 16. 抜け

- 視線が遠くまで届くほど広く感じる。だから**視線が抜けるようにプランする**

### 17. 実際の家でどう考えたのか

- **期待感が高まるアプローチ**をつくる
- 一棟ごとの考え方は [施工事例](works/README.md) に記録する（[記入テンプレート](works/_template.md)）

### 18. デザインについての考え方

- 誰が見ても美しいものは美しい
- シンメトリー、黄金比など、**綺麗に見えるには理由がある**
- **価値はデザインに宿る**
