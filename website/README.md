# ホームページ制作の材料

ホームページに載せる原稿・データを、ページごとに蓄積するフォルダです。
元の資料（PDFなど）は [`sources/`](../sources/) に日付ごとに保存し、ここにはその書き起こしを置きます。

- 書き起こしは**原文のまま**です。誤字や表現の修正案は、下の「確認が必要な点」にまとめ、本文は勝手に直していません
- 原稿の中の「←ボタンがほしい」「←名言風に写真と一言」などの指示書きは「制作メモ」として残しています

## 確認が必要な点

公開前に確認・判断していただきたい点です。

### 数字・事実の食い違い

- [ ] **施工手引書の改定頻度**：「毎年改定」と「年２回の改定」が両方あります（施工技術③）
- [ ] **施工手引書の単位**：見出しは「43枚」、本文は「43ページ」
- [ ] **現場監査記録書の分量**：「80〜100ページ」と「91ページ」が両方あります（施工技術⑦）
- [ ] **10回の監査は誰が行うか**：③では「社内外の監査員」、④ではネクストステージが「合計10回」とあります。社内監査とネクストステージの監査が同じ10回なのか、別なのかを明確に
- [ ] **⑦の見出し**：「全　の検査項目」の数字が空欄（315と思われます）
- [ ] **コンクリート強度の単位**：「24N/㎡」は「24N/mm²」の誤りと思われます
- [ ] **施工事例の竣工年**：「2027年」「竣工から1年」となっており、見本用の仮の内容と思われます。取材し直す際に差し替えを

### 表現上の注意（広告の決まりごと）

- [ ] **「全国トップクラス」**（C値0.21）：比較の根拠（どの調査・統計と比べたか）を示せないと、景品表示法上の「優良誤認」と受け取られるおそれがあります。根拠を添えるか、「C値0.21（直近10棟平均）」と数字だけで語る方が安全です
- [ ] **「一般的な住宅は2.0程度」「10回という監査回数は業界の中でも非常に手厚い」**：同様に出典を添えるのが望ましいです
- [ ] **ZEH基準・省エネ基準の数値**：UA値の基準（0.6／0.87）は地域区分によって異なります。大分の該当地域区分を確認し「〇地域の場合」と書き添えると正確です
- [ ] **「高く売ることができる」**（資産価値④）：将来の売却価格を約束していると受け取られないよう、「売却時に選ばれやすい」などの言い方を検討
- [ ] **「メンテしやすい設計と長期保証」**（資産価値 理由４）：見出しに「長期保証」とありますが、本文に保証の内容がありません。保証の期間・範囲を書くか、見出しを調整
- [ ] **比較表「価値が消える家」**：「下請け任せ。品質基準がない」などは他社を一律に否定する表現に読めます。「一般的に〜になりがち」など、角が立たない言い方も検討を

### 施工事例の個人情報
