# 富裕層へのアプローチ戦略

[ブランド構築戦略](strategy.md)を土台に、富裕層のお客様にどう出会い、どう選ばれるかをまとめたものです。
共有用ドキュメント「樹の家こころ舎 ブランド構築戦略」（2026年11月27日版）の富裕層の章と同じ内容です。

樹の家こころ舎は「本来の自分に戻れる家」を約束し、富裕層とは広告ではなく、紹介と完全予約制のアトリエ体験で出会います。

富裕層に対して特に強いのは、差別化の3本柱のうち「②描いた通りに建てる」と「③住み継がれる財産」です。「預かった大きなお金が確かに形になり、価値として残る」ことを、事実と数字で示せるからです。

---

## 1. 狙うお客様像

大分中心部から1時間圏内で、「お金はあるが、時間と心の余白がない人」を狙います。代表挨拶の「経営者として、社会人として、親として」という一節は、まさにこの人たちに届く言葉です。

| 優先 | お客様像 | 家に求めるもの | 当社との接点 |
|---|---|---|---|
| A | 開業医・歯科医 | 仕事で気を張るぶん、家では役を降りたい。窓口を一つにしたい | 施工事例案（臼杵市）がそのまま当てはまる |
| A | 中小企業の経営者・二代目 | 価値が残るもの、本物、人に誇れる家 | 資産価値・デザインの普遍性が刺さる |
| B | 士業（弁護士・税理士など） | 根拠のある品質、説明できる数字 | 施工手引書・現場監査記録書が刺さる |
| B | 土地を持つ家の後継ぎ（建て替え） | 親の家の記憶を残したい、次の世代に渡したい | 記憶の設計と資産継承の両方が刺さる |
| C | 移住・二拠点（都市部の経営者や専門職） | 自然と景色、非日常の入口 | 土地を読む設計、立地の資産性 |

共通するのは、**「広告より信頼できる人の紹介で動く」「安さより失敗しないことを重んじる」「何もかも自分で決める日常に疲れている」**の3点です。

## 2. 富裕層が家づくりで求めるものと、当社の答え

富裕層が買うのは「高級な家」ではなく、「任せて間違いのない相手」と「自分だけの答え」です。当社の既存の強みは、そのまま答えになります。

| 富裕層の本音 | 当社の答え | 見せ方 |
|---|---|---|
| 時間がない。何度も打ち合わせに呼ばれたくない | 設計から外構・住設まで窓口が一つ。5つの社内会議で「言った言わない」を防ぐ | 打ち合わせの回数と流れを最初に示す |
| 失敗したくない。大金を預ける相手を見極めたい | 全棟の気密測定、315項目の現場監査記録書、第三者2社のチェック | アトリエで記録書と手引書の実物を見せる |
| 誰かと同じ家は嫌だ | 記憶のヒアリングから始める、その人だけの設計 | 事例を仕様ではなく物語で見せる |
| 見栄ではなく、本物がほしい | 住宅は作品ではない。素材と光と動線で心地よさを設計する | 「高級」と言わず、素材と光を体験させる |
| 資産として残るか | 普遍的なデザイン、数値で証明された性能、長期修繕計画 | 資産価値ページと比較表 |
| 家族や次の世代に誇れるか | 住み継がれる財産、資産継承 | 竣工後の暮らしを取材した物語 |

## 3. 出会う場所：紹介網と接点

富裕層とは、広告ではなく「信頼されている人からの紹介」で出会います。接点を効果の高い順に並べます。

| 優先 | 接点 | やること |
|---|---|---|
| 1 | OBのお客様 | 富裕層の友人は富裕層です。竣工後1年の訪問と取材、OB宅での少人数の内覧会を定例化する |
| 2 | 税理士・金融機関の富裕層担当・FP | 建て替えや相続の相談を受けている人たち。資産価値の考え方と品質の証拠をまとめた資料を渡し、定期的に情報交換する |
| 3 | 医療の開業支援をしている会社・医薬品卸 | 開業医は開業と前後して自宅を建てることが多い。CASE 01の物語を使う |
| 4 | 不動産会社・地主 | 良い土地の情報は先に富裕層へ流れる。自社の不動産事業とつなげ、土地探しから伴走する |
| 5 | 経営者の集まり | 商工会議所、法人会、経営者向けの勉強会など。営業ではなく、代表が「住宅価値」を語る講演で入る |
| 6 | HP・Instagram | 紹介された人が必ず確かめに来る場所。一番の役割は「信頼の裏付け」で、集客は二の次 |

紹介者には、「紹介しても自分の信用が傷つかない」と思える材料（施工事例の小冊子、数値、監査体制）を渡します。紹介料よりも、この安心の方が紹介を生みます。

## 4. アトリエでの体験と商談の進め方

「五感の家（アトリエ）」の完全予約制プライベート相談会を、富裕層との商談の中心にします。見学会のような「大勢の中の一人」ではなく、「自分のために用意された時間」にします。

1. **予約の前**：紹介者から人柄と関心を伺う。日時は平日の夜や日曜など、お客様の都合に合わせる
2. **到着**：代表が自ら出迎える。アプローチから玄関に入るまでの「期待感」を体験してもらう
3. **体感**：説明する前に座ってもらう。壁を這う光、素足で歩く床、静けさを体で感じてから、理由を話す
4. **記憶のヒアリング**：子どもの頃の家、旅先で心地よかった場所を伺う。仕事の話ではなく「その人自身」の話を聞く
5. **証拠を見せる**：施工手引書、現場監査記録書、C値・UA値の実測値を手に取って見てもらう
6. **次の一手**：希望されれば、候補地を一緒に歩く「土地を読む日」を設ける

契約後も、素材の産地を一緒に訪ねる（CASE 01の大分の石材のように）、棟梁が現場で説明する、などの「自分だけの体験」を続けます。この体験が、そのまま次の紹介で語られる物語になります。

## 5. 価格と資産価値の語り方

価格は隠さず、値引きもしません。富裕層は「安いか」より「なぜこの金額なのか」を知りたがります。

- **参考価格を示す**：施工事例ごとに参考価格を載せる（CASE 01は3900万円）。税込みか、外構込みかを明記する
- **金額の内訳を理由で語る**：社内大工、三重チェック、地元の石や木など、「何にお金が使われているか」を見せる
- **値引きしない**：値引きは「元の金額に根拠がなかった」と受け取られ、信頼を損なう。予算の調整は「兼ねる」設計で応える
- **資産価値は「約束」ではなく「考え方」として語る**：「高く売れます」ではなく「30年後も選ばれる条件を整えます」と言う
- **税金・相続の話は専門家と組む**：相続や資産の組み替えに関わる判断は、提携する税理士に任せる。当社は「家そのものの価値」を担う

富裕層への最も強い言葉は、代表の「誰でもできることを、誰もできないくらい真剣に」です。価格の説明はこの一文に帰着させます。

## 6. やらないこと

富裕層は「自分を狙っている」と感じた瞬間に離れます。次のことはしません。

| やらないこと | 理由 |
|---|---|
| 「富裕層向け」「ラグジュアリー」「高級住宅」と名乗る | 本物を求める人ほど、肩書きの言葉を嫌う。「住宅は作品ではない」とも矛盾する |
| チラシの大量配布、割引キャンペーン | 「誰にでも売る会社」に見え、希少性を損なう |
| 架電やしつこい追客 | 時間を大事にする人ほど嫌う。連絡はお客様のペースに合わせる |
| 施主様が特定できる事例紹介 | 富裕層はプライバシーを最も重んじる。「臼杵市・開業医・H様」のような組み合わせは避ける |
| 他社の悪口 | 紹介者の信用を引き下げる。比較は「一般的に、〜になりがち」という事実だけで語る |
| 根拠のない「全国トップクラス」 | 数字を確かめる人ほど、根拠のない言葉で信頼を失う。数字だけで十分 |

## 7. 最初の90日でやること

紹介者に渡せる材料をそろえ、最初の紹介経路をつくることが目標です。

- [ ] OBのお客様のうち、富裕層の方・経営者の方をリストにする
- [ ] CASE 01のオーナーインタビューをやり直し、個人が特定されない形で仕上げる
- [ ] 紹介者に渡す小冊子をつくる（代表挨拶・施工事例・品質の数字・資産価値の考え方）
- [ ] アトリエのプライベート相談会の流れを社内でそろえる
- [ ] 税理士・金融機関・医療の開業支援会社から、提携先を3社候補に挙げ、代表が直接訪ねる
- [ ] OB宅での少人数内覧会を1回開く

### 成果の確かめ方

| 見るもの | 意味 |
|---|---|
| 紹介経由の相談件数 | 紹介網が動いているか |
| アトリエ相談からの契約率 | 体験が信頼につながっているか |
| 1棟あたりの契約金額 | 狙うお客様に届いているか |
| 値引きの件数 | 価格の説明が納得されているか（0件が目標） |
| OBからの再紹介 | 住んだ後も満足しているか |
