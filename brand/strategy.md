# ブランド構築戦略

株式会社樹の家こころ舎のブランドを「何を約束し、どう伝え、どう体験していただくか」の順に整理した戦略書です。
内容は [README](../README.md) に記録した経営理念・設計思想・沿革をもとにしています。新しい言葉や事実が加わったら、この文書も更新します。

富裕層のお客様へのアプローチは [富裕層へのアプローチ戦略](富裕層戦略.md) にまとめています。

---

## 0. 現状認識

### すでにある強い資産

| 資産 | 内容 | ブランドでの価値 |
|---|---|---|
| 一貫した設計思想 | 「言葉になる前の感覚を、素材と光と空間の流れで設計する」 | 他社がまねしにくい「考え方」での差別化ができる |
| 代表の言葉 | 「俺の家や」「静寂とは刺激が入らない状態」「間取りは要望の最大公約数ではない」など | そのままコピーになる、体温のある言葉 |
| 設計×施工の一体経営 | 「自分が社長になればいいんだ」から始まった工務店経営 | 「描いた通りに建つ」ことの裏付け |
| 長い実績 | 2004年 設計事務所開設、2008年 法人化 | 20年以上続いている信頼 |
| 物語を記録する仕組み | 施工事例テンプレート（記憶・土地・光・素材…） | 事例を「仕様の一覧」ではなく「物語」として発信できる |

### 課題

1. **言葉が多く、ひと言にまとまっていない**：思想は18項目あり、初めての人には入口が分かりにくい
2. **「心地よさ」「自然素材」は競合も使う言葉**：それだけでは違いが伝わらない
3. **施工事例がまだない**：思想を裏付ける「実物の物語」が発信されていない
4. **社名の由来・得意な家づくりが未整理**：ブランドの根っこの説明が欠けている

## 1. ブランドの核

### ブランドエッセンス（ひと言）

> **本来の自分に戻れる家**

社会では役を演じて過ごす人が多い。家に帰ったら、素の自分に戻れる。
完成した家を見て「**俺の家や**」と感じていただける。
樹の家こころ舎がつくるのは、そういう居場所です。

> **ホームページのキャッチ（HP構成案で決定済み）**
> メイン：「言葉になるより前の感覚を設計する」／サブ：「設計家が最初の線から、最後の釘まで」
> キャッチは「どう設計するか」、エッセンスは「お客様に何が残るか」を表します。キャッチで入口をつくり、エッセンスは代表挨拶や施工事例の物語の中で伝える、という使い分けを想定しています。

### ブランドの約束（お客様へ）

> あなたの記憶の中にある心地よさを、素材と光と空間の流れで形にし、
> 住み継がれる財産として残します。

### 存在意義（社会へ）

> 家が財産になることを、日本の当たり前にする。

### ブランドピラミッド

```
              ┌──────────────┐
              │ 本来の自分に │  ← エッセンス
              │ 戻れる家     │
            ┌─┴──────────────┴─┐
            │ 安らぐ／自分らしい │  ← お客様が感じる価値（情緒）
            │ 誇れる／受け継げる │
          ┌─┴──────────────────┴─┐
          │ 記憶と五感の設計       │  ← 提供する価値（機能）
          │ 描いた通りに建てる技術 │
          │ 住み継がれる財産価値   │
        ┌─┴──────────────────────┴─┐
        │ 経営理念：心地よさの追求／  │  ← 根拠
        │ 顧客第一／日本の住宅価値を高める │
        └──────────────────────────┘
```

## 2. ポジショニング

### 住宅会社の地図

|  | 住む人の感覚を中心に | つくり手の表現を中心に |
|---|---|---|
| **設計と施工が一体** | **樹の家こころ舎** | — |
| **設計と施工が別** | 一般的な工務店（要望を積み上げる） | 作家性の強い設計事務所（作品としての住宅） |
| **規格・性能が中心** | ハウスメーカー（数値と保証で選ばれる） | — |

樹の家こころ舎は「**住宅は作品ではない**」と言い切りつつ、「**価値はデザインに宿る**」とも言う、両方を持つ会社です。
「作品志向の設計事務所」とも「要望をそのまま形にする工務店」とも違う場所に立ちます。

### 差別化の3本柱

| 柱 | 一文で | 証拠（言えること・見せられること） |
|---|---|---|
| ① 記憶と五感の設計 | 要望ではなく、記憶の中の心地よさから設計する | 記憶のヒアリング、感じたことを先に図面化、洞窟・土間・光を壁に這わせる窓 |
| ② 描いた通りに建てる | 設計した人の会社が、建てるところまで責任を持つ | 設計事務所×工務店の成り立ち、棟梁のやり方がそのまま施工手引書、技術者として育てるスタッフ |
| ③ 住み継がれる財産 | 住み終えたら解体する家ではなく、次の人も住みたくなる家 | 素材の経年変化、原理原則（太陽・風）に沿った設計、普遍的な美しさ（シンメトリー・黄金比） |

「自然素材」「デザイン住宅」「高性能」は、この3本柱を支える**手段**として語り、主役にしません。

## 3. 届けたい人

### 中心となるお客様像

- 外では気を張って過ごしていて、**家では素の自分に戻りたい**と感じている
- 間取りや設備の「足し算」より、**居心地**を大事にしたい
- 流行りの家より、**長く愛せて、価値が残る家**を望んでいる
- 自分の感覚を言葉にするのは得意でなくても、**「なんかいい」を分かってくれる人**を探している

### このお客様の不安と、当社の答え

| 不安 | 当社の答え |
|---|---|
| 要望をうまく伝えられない | 言葉になる前の感覚をヒアリングし、図面にするのが私たちの仕事です |
| 設計事務所に頼むと、作品にされそう | 住宅は作品ではありません。住む人の居場所です |
| 図面は良くても、その通りに建つのか | 設計した会社が、そのまま施工します |
| 建てたあと価値がなくなるのでは | 住み継がれる財産になる家をつくります |

## 4. ブランドストーリー

発信の土台になる物語です。ホームページの会社紹介、見学会での挨拶、採用説明会などで共通して使います。

1. **始まり**：2004年、26歳で設計事務所「シェルター研究所」を開設。シェルターには「住まい」という意味もある
2. **壁**：若い設計士の言葉を、現場の職人さんがなかなか聞き入れてくれない。工務店の社長の言うことはみんな聞くのに
3. **決断**：「自分が社長になればいいんだ」。2008年、設計事務所×工務店として樹の家こころ舎を設立
4. **気づき**：心地よさを表現する設計と、それを形にする技術。両方がそろって初めて、思い描いた家が建つ
5. **いま**：住む人の記憶の中にある心地よさを、素材と光と空間の流れで形にしている
6. **これから**：家が財産になることを、日本の当たり前にする

> 代表自身が「安易な考えで」と笑って語る始まりは、飾らない人柄を伝える貴重なエピソードです。きれいに整えすぎず、そのまま使います。

## 5. 言葉の決まりごと

### 繰り返し使うキーワード

| キーワード | 使い方 |
|---|---|
| 本来の自分に戻れる | エッセンス。会社紹介・広告の最初の一文に |
| 記憶・原風景 | 設計の出発点を語るとき |
| 素材感・五感 | 「自然素材」と言いたいときは、五感の体験として言い換える（例：足裏のひんやり） |
| 刺激を引く・静寂 | 間取りや光の考え方を語るとき |
| 描いた通りに建てる | 設計×施工の強みを語るとき |
| 住み継がれる・財産 | 家の価値・将来を語るとき |

### 言い換えの例

| 避けたい言い方 | こう言う |
|---|---|
| こだわりの自然素材 | 素足で歩きたくなる床 |
| おしゃれなデザイン住宅 | 誰が見ても美しい、理由のある形 |
| 開放的な大空間 | 視線が遠くまで抜ける、落ち着いた広がり |
| 明るい大きな窓 | 光が壁を這う、高い位置の窓 |
| ご要望をすべて叶えます | ご要望を「兼ねる」ことで、ひとつの場所にまとめます |
| 作品・建築作品 | （使わない）住まい・居場所 |

### 語り口

- **静かで、言い切る**：形容詞を重ねず、短い文で
- **体の感覚で語る**：「涼しい」「ひんやり」「ほっとする」など、五感の言葉を選ぶ
- **代表の言葉は原文の温度を残す**：「うちはやろう」「俺の家や」は整えすぎない
- **誇張しない**：「最高」「業界No.1」は使わない。当たり前を積み重ねる会社らしく

## 6. 見た目の決まりごと

設計思想「刺激を引く」「光をコントロールする」を、そのまま見た目のルールにします。

### 写真

- **光と影**：壁を這う光、高窓からの光をとらえる。全室を明るく飛ばした写真は避ける
- **素材の寄り**：床・壁・土間の質感が分かるアップを必ず入れる（写真を見て記憶が呼び起こされるように）
- **抜け**：室内から庭・空・遠景へ視線が抜ける構図
- **アプローチの順番**：道路 → アプローチ → 玄関 → 室内、の順で並べ、期待感の高まりを追体験できるようにする
- **暮らしの気配**：人物は小さく、後ろ姿や手元で。モデル撮影のような演出はしない

### デザイン

- **余白を多く**：情報を詰め込まない。1ページに伝えることはひとつ
- **色**：木・土・漆喰・石など、実際に使う素材から色を取る（具体的な色見本は今後決める）
- **文字**：本文は読みやすい明朝体か、落ち着いたゴシック体。装飾的な書体は使わない
- **比率**：シンメトリーや黄金比を、レイアウトにも取り入れる

## 7. 顧客体験の設計

ブランドは広告ではなく、**お客様が実際に体験すること**で決まります。家づくりの各段階で、ブランドの約束を体験していただく場面をつくります。

| 段階 | 体験していただくこと | 具体策 |
|---|---|---|
| 知る | 「この会社は考え方が違う」 | 施工事例の物語、代表の言葉の発信 |
| 訪ねる | 「本来の自分に戻れる」を体で感じる | モデルハウス・OB宅で、玄関に入った瞬間・素材の手触りを体験してもらう案内 |
| 相談する | 「言葉にしなくても分かってもらえた」 | **記憶のヒアリング**（心地よかった場所・原風景・子どもの頃の家）を初回相談の定番にする |
| 設計する | 「要望の足し算ではない」 | 要望を兼ねた理由を、図面とともに説明する。土地の風・太陽を読んだ説明書を添える |
| 建てる | 「描いた通りに建っている」 | 設計担当と棟梁がそろう現場説明、施工中の様子の定期報告 |
| 住む | 「俺の家や」 | 引き渡し時に「この家の物語」（事例テンプレートの内容）をお渡しする |
| 住み継ぐ | 「財産として価値が残る」 | 定期点検、手入れの方法、将来の売却・継承の相談窓口 |

## 8. 発信の計画

### 発信の柱

| 柱 | 内容 | 頻度の目安 |
|---|---|---|
| 施工事例の物語 | テンプレートに沿って、記憶・土地・光・素材から書き起こす | 1棟ごと |
| 代表の言葉 | 設計思想を1つずつ、写真1枚と短い文章で | 週1回 |
| 棟梁・技術者の仕事 | 材料を生かす施工、現場の工夫、当たり前を積み重ねる姿 | 月2回 |
| 住み継がれた家 | 数年・十数年住んだお宅の今（素材の経年変化、暮らしの変化） | 年数回 |

### 発信の場

- **ホームページ**：すべての発信の受け皿。会社紹介・設計思想・施工事例・ブランドストーリー
- **Instagram**：写真中心。光と素材と抜けを見せる
- **見学会・OB宅訪問**：体験の場。ブランドの約束を最も強く伝えられる
- **紙の冊子**：設計思想と事例をまとめた小冊子。相談時・見学会でお渡しする

### 施工事例の運用

- 竣工のたびに `works/_template.md` で記録する
- 撮影前に「この家で感じてほしい感覚」を決め、写真の説明文に書く
- まずは**過去の代表的な3棟**を、お客様の了承を得て記録するところから始める

## 9. 社内に根づかせる

ブランドは、スタッフ一人ひとりの振る舞いで伝わります。

- **設計思想の勉強会**：README の18項目を、毎月1テーマずつ実例とともに話し合う
- **ヒアリングの型をそろえる**：記憶・原風景を伺う質問集をつくり、誰が担当しても同じ体験を届ける
- **棟梁の手引書を整える**：「棟梁のやり方が施工手引書」を文書にし、技術者育成の教材にする
- **言葉の決まりごとを共有**：本書5章を、営業・設計・現場で共通の言葉にする
- **採用でも同じ物語を語る**：「設計も施工も分かる技術者になれる会社」を採用のメッセージにする
