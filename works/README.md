# 施工事例

設計思想が実際の家でどう形になったかを、一棟ごとに記録します。
「施工事例にも物語が必要」という考えに基づき、仕様だけでなく、お客様の記憶や、土地で感じたことから書き起こします。

## 新しい事例の書き方

1. [`_template.md`](_template.md) をコピーし、「年-地域-愛称.md」という名前で保存します（例：`2026-〇〇市-土間の家.md`）
2. テンプレートの問いに答えながら書き込みます
3. 写真は `images/` フォルダに保存します
4. 下の一覧に1行追加します

※ お客様のお名前や正確な住所など、個人を特定できる情報は書かないでください。掲載前には必ずお客様の了承を得てください。
